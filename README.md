# World Class: React-база дизайн-системы

Дизайн-система World Class в коде: токены (Primitive, Semantic, типографика, motion) и React-компоненты на них, плюс каталог компонентов в Storybook. Источник — дизайн-система в Figma; Node ID каждого компонента указан на его странице в Storybook.

Стек: Vite + React + TypeScript, CSS Modules, Storybook.

| Команда | Что делает | Адрес |
|---|---|---|
| `npm run storybook` | Каталог компонентов (Storybook) | http://localhost:6006 |
| `npm run dev` | Тестовая страница Showcase | http://localhost:5173 |
| `npm run build` | Проверка типов и сборка приложения | — |
| `npm run build-storybook` | Статичная сборка каталога в папку `storybook-static/` | — |

## Storybook: запуск и остановка

### Первый запуск на компьютере

Нужен Node.js 18+ (проверка: `node -v`). Один раз установите зависимости:

1. Склонируйте репозиторий и перейдите в его папку:
   ```bash
   git clone https://github.com/rybin-aleksey/worldclass_ds_handoff.git
   cd worldclass_ds_handoff
   ```
2. Установите зависимости (несколько минут):
   ```bash
   npm install
   ```

### Запустить

```bash
npm run storybook
```

Через 5–10 секунд в терминале появится рамка **Storybook ready!** с адресом, и каталог откроется в браузере сам. Если не открылся — перейдите на http://localhost:6006.

Терминал при этом занят сервером — это нормально. Не закрывайте его, пока работаете с каталогом. Для других команд откройте второй терминал (кнопка **+** в панели терминала).

### Остановить

В терминале, где запущен Storybook, нажмите **Ctrl+C**. Если спросит «Terminate batch job (Y/N)?» — введите `Y` и Enter.

Закрыть вкладку браузера недостаточно: сервер продолжит работать, пока не остановлен в терминале.

### Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| «Port 6006 is not available. Would you like to run Storybook on port 6007 instead?» | Storybook уже запущен в другом терминале. Ответьте `n` и откройте http://localhost:6006 — или остановите старый сервер (ниже). |
| Сервер запущен, но терминал закрыт, и Ctrl+C нажать негде | В PowerShell: `Get-NetTCPConnection -LocalPort 6006 -State Listen \| ForEach-Object { Stop-Process -Id $_.OwningProcess }`. Для Showcase замените 6006 на 5173. Либо перезапустите VS Code. |
| Красная ошибка на странице после перезапуска сервера | Обновите страницу без кэша: **Ctrl+F5**. |
| `importers[path] is not a function` | Исправлено в `.storybook/main.ts` (регистр буквы диска в Windows). Если повторится — перезапустите Storybook и нажмите Ctrl+F5. |
| `npm: command not found` / `node: command not found` | Установите Node.js LTS с nodejs.org и перезапустите VS Code. |

Showcase (`npm run dev`) запускается и останавливается так же.

## Storybook: как пользоваться

### Разделы (левая панель)

- **Foundation** — переменные ДС: палитра примитивов, смысловые цвета (с примитивом, на который ссылаются), типографика, отступы и радиусы, анимация. Значения читаются прямо из `src/tokens/*.css`.
- **Components** — каждый компонент в изоляции. Сгруппированы как разделы страницы Components в Figma: Actions, Inputs, Selection, Navigation, Cards, Information, плюс Icon.

Поиск по каталогу — поле **Find components** вверху (`Ctrl+K`).

### Страница компонента

У каждого компонента первым пунктом идёт **Docs**:

- описание и Node ID компонента в Figma — по нему компонент находится в файле;
- живой пример и таблица пропсов: имя, описание, значение по умолчанию и **контрол** — меняйте значения прямо в таблице;
- **Show code** под примером показывает JSX текущего варианта, **Copy** копирует его — это готовый код для разработчика;
- ниже — все stories компонента.

Остальные пункты — отдельные stories: именованные варианты (Primary, Disabled, Error…) и **AllVariants** — вся матрица вариантов × состояний на одном холсте. Её удобно сверять с Figma.

### Панель снизу

- **Controls** — те же контролы, что на Docs: переключайте варианты и состояния, меняйте тексты.
- **Actions** — журнал событий: клики, изменения, переключения.

Интерактивные компоненты работают по-настоящему: кнопка нажимается, флажки, переключатели и вкладки переключаются по клику, лайк ставится.

### Панель инструментов сверху

- **Backgrounds** — фон холста: `bg/mainWhite`, `bg/baseGray`, `bg/pictureBg`.
- **Grid**, **Measure**, **Outline** — сетка, линейки размеров при наведении и контуры блоков. Удобно для сверки отступов с Figma.
- Масштаб, полноэкранный режим, **Open canvas in new tab** — открыть story отдельно.

### Как сверять с Figma

1. Откройте компонент → **AllVariants**, рядом — набор в Figma по Node ID из описания.
2. Включите **Measure** и наведите на элементы, чтобы сравнить размеры и отступы.
3. Расхождения фиксируйте задачей с указанием компонента и Node ID.

Изменения в коде появляются в открытом каталоге сами, обновлять страницу не нужно.

## Структура

- `src/tokens/primitives.css` — примитивы (литералы только здесь)
- `src/tokens/semantics.css` — смысловые и компонентные токены, только `var(--primitive)`
- `src/tokens/typography.css` — 17 Text styles как классы `.ds-*` без цвета
- `src/tokens/motion.css` — длительности и easing переходов (добавлено для Storybook, в ДС нет)
- `src/components/<Name>/` — компонент, CSS Module, index, `<Name>.stories.tsx`; общий реэкспорт в `src/components/index.ts`
- `src/components/Icon/icons.ts` — 25 SVG-иконок из Figma; `src/assets/icons/activity.png` — растровая иконка «Активность»
- `src/assets/membership/` — арт клубных карт из Figma
- `src/foundation/` — раздел Foundation в Storybook
- `src/Showcase.tsx` — тестовая страница: палитра, шкала текста, галерея компонентов
- `.storybook/` — конфиг Storybook: подключение токенов, порядок разделов, фоны

## Правила

- Имя = якорь: `bg/mainWhite` → `--bg-mainWhite`, `Header / Navbar` → `<HeaderNavbar>`.
- В стилях только токены, без прибитых значений. Новые токены и компоненты — только после появления в дизайн-системе.
- Иконки — SVG из Figma: `<Icon name="24px / calendar" />`, цвет наследуется (`currentColor`) — задавайте токенами `icons/*`.
- Шрифт Avenir Next Cyr не вложен (лицензия): нужен файл шрифта, иначе работает фолбэк.
